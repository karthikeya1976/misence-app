# test_auth_security.py) requires httpx at runtime — FastAPI does not
# declare it as a hard dependency, only as an optional extra. This was
# ALREADY broken before the CI Postgres service container was added
# (PR #50): every one of those test modules pytest.skip()'d at collection
# whenever POSTGRES_URL was unset, which masked the missing httpx import
# error entirely. Once the service container let those modules actually
# collect, CI failed immediately with "The starlette.testclient module
# requires the httpx package to be installed" — 34 errors, confirmed via

# because installing `fastapi[all]` (done ad hoc, not via this file) pulls
# httpx in as a side effect.
